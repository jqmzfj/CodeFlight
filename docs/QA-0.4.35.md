# 0.4.35 共用窗口缩放控件

## 问题与实现

0.4.34原生复核发现：鼠标从窗口边缘缩放时不经过控件resize方法，AX尺寸保留先前值；缩放角的辅助功能焦点与键盘可达性也未明确实现。

- AX值改为查询当前窗口的内容尺寸，包含初始值、原生边缘缩放与辅助功能增减；避免标题栏高度混入读数，不新增缓存或轮询。
- 增加焦点读写、聚焦动作与可见焦点环；加入原生key view循环，方向键4pt、Shift方向键24pt，Tab／Shift-Tab离开控件，避免焦点陷阱。按窗口只初始化一次键盘循环，不随输入反复重建。
- 最小尺寸修正与全部缩放操作继续仅作用于所属sheet，普通窗口不受影响。帮助文字说明方向键和Shift操作。

## 验证

- 3项SheetWindowSizingTests最终通过，0失败，1.616秒（.build/production-075-sizing-tests-final.log）：实际AppKit sheet原生setContentSize后的实时读数、SwiftUI式最低约束被替换后的保护、AX增减、聚焦与4／24pt方向键、Tab两向离开，以及非sheet拒绝操作。测试直接给控件传递按键事件，不能替代最终App的真实键盘链路。
