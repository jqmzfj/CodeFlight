# 0.4.46 窗口布局与文件导航稳定性

## 调整

- 主窗口由 AppKit 维持 `1120×720` 的最低内容尺寸；恢复过小的旧窗口时自动纠正，并合并重复的尺寸检查任务。
- 左侧工具栏宽度支持拖动调整（36–72pt），双击分隔线恢复 44pt 默认值并持久化。
- 底部工具窗口支持 Xcode 风格的展开／收起过渡，运行进程、服务与 Docker、终端、Git 树分别保留布局高度。
- 文件树目录异步展开期间显示读取状态和辅助功能语义；Git 状态着色改为无临时数组扫描，减少大仓库导航时的分配。

- 本轮未访问或修改业务项目、PHP 文件及测试仓库状态。
