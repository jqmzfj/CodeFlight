# 0.4.47 界面层级与窗口质感

本版本在 0.4.46 的稳定性基础上统一了窗口层级的视觉语义：项目标签、左侧工具栏、编辑器标签和底部工具窗口使用同一套自适应系统色、分隔线和选中态；项目导航显示项目路径；工具栏选中项增加细窄强调线，工具栏本身支持拖动宽度并保留最低尺寸；终端会话标签按当前语言显示，悬停时显示关闭操作，当前会话有独立选中指示。

## 验证

- `swift build` 通过。
- `swift test` 全量 306 项通过，0 失败。
- 针对项目标签、窗口尺寸和主题的 7 项测试通过。
- 正式打包脚本完成后，以脚本输出的 306 项全量回归、Universal 2、签名、runtime smoke、ZIP/DMG 校验为发布依据。
