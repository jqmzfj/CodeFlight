# 0.4.42 差异模式切换阅读位置

## 调整

双栏和统一视图使用修改块、原版行号和新版行号映射阅读位置，不按滚动百分比恢复。每个显示行使用原生 AppKit marker 注册实际行框架，由对应滚动容器的 bounds 变化驱动首个可见行记录；切换后先由 `ScrollViewReader` 建立目标行，再用原生 clip view 的实际坐标校正到顶部。替换优先匹配新版行，纯删除匹配原版行，无对应行时回退到同一修改块标题。文档变化会清除位置状态并创建新的 tracker，避免旧行缓存污染新文档。

项目首屏预览在根目录只有文件夹时，按目录逐层查找首个文件并即时释放中间列表，避免为大型仓库递归构建完整内存树。

运行配置环境变量序列化改为可恢复编码，避免异常配置数据触发崩溃。

运行配置窗口存在未保存草稿时，项目切换会被拦截并保留编辑内容；无未保存修改时才会随项目切换自动关闭。

项目 Tab 采用固定的紧凑宽度范围，激活态使用单一底部强调线，悬停态仅增加轻量背景，并补充选中状态的辅助功能标记，避免多项目切换时标签宽度跳动。

左侧工具栏按钮和底部设置按钮增加低对比度悬停反馈，激活工具增加细描边；文件导航树按 Git 状态为冲突、未暂存和已暂存文件提供原生系统色提示，同时保留干净文件的低干扰外观；关闭项目时立即释放该项目的运行输出流，避免后台进程收尾期间继续保留项目 UI 状态。

顶部项目 Tab 支持右键菜单，可直接在 Finder 中定位项目或关闭项目，适合同时管理多个仓库。

代码预览补充类型声明高亮，使用适配浅色／深色主题的蓝色语义色，更接近 Xcode 的源代码阅读层次。

编辑器文件 Tab 支持右键复制完整路径、在 Finder 中显示和关闭文件，减少多项目下的定位操作。

命令面板新增 `⌘P` 快速打开文件：自动切换到文件导航并聚焦筛选框，按 `Esc` 退出筛选焦点，保持 IDE 常用快捷路径。

工作台菜单补充 Git 更改、运行进程、服务与 Docker、Git 树的键盘入口；修正主题切换与新建终端的 `⌘⇧T` 快捷键冲突，主题切换改为 `⌘⇧D`。这些入口通过状态请求驱动主窗口工具栏，避免菜单动作与视图局部状态脱节。

新增 `⌘J` 显示／隐藏底部工具窗口，切换时保持当前工具类型、会话和已保存高度；最终 App 中验证终端隐藏后恢复，Terminal 1 会话和输入焦点仍在。

命令面板最终 App 复核：打开后搜索框自动聚焦，输入“设置”只保留“打开设置”，回车进入设置窗口；设置窗口的“完成”按钮关闭后恢复主窗口和原有 Git／终端状态。Esc 关闭链路也保留。

顶部 Git 分支控件显示实际领先／落后提交数；上游失效时显示橙色告警，避免用户必须打开 Git 面板才能判断 Push／Pull 状态。

三项回归覆盖不等长替换、纯新增／删除、无末尾换行、块标题和无效位置、预加载及非有限几何值。原生 tracker 通过弱引用管理懒加载行，并在行离开窗口时解除注册。
