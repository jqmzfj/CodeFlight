# 0.4.19 预览搜索范围一致性

## 问题与修改

原搜索统计使用读入文本，导航与高亮使用经过行数／单行限制和换行归一化后的显示文本。超过显示限制的匹配会出现有计数却无法跳到的情况。

- 预览准备完成后，将同一份不可变PreparedCodeDocument快照提供给工具栏，计数、导航、高亮及状态栏行数使用同一显示缓冲。String／Array共享写时复制存储，不重新准备第二份文档，也不建立全匹配索引。
- 快照同时校验文件路径与源内容；按文件路径和内容取消／重启准备任务。同内容文件切换也会发布对应快照。准备期间匹配计数显示省略号，导航不可用；文档变化清理旧导航请求。
- 删除工具栏单独扫描读入文本统计换行的任务，使用已有行偏移数量。空文件显示0行／0匹配；二进制、无法读取或差异模式不提供文本搜索入口。
- 匹配数量说明改为“当前显示的预览内容中的匹配次数”。截断内容仍在预览顶部明确提示。
