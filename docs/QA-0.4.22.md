# 0.4.22 Reflog 交互与分页

## 修改

- 读取服务返回明确的entries／hasMore／failure，不再将命令失败、截断或格式损坏伪装成空历史。错误完整可选、可滚动，并提供重试；真正空历史与无匹配筛选有独立提示。
- 分页每次读取有界前缀，核对当前已加载记录的身份；已有记录移动时要求刷新，避免可变reflog索引造成漏项或重复。4MB读取上限保留；不是复制全部仓库或预加载所有记录。
- 筛选同步选择和详情；无匹配时不会显示被隐藏记录的提交检查器。刷新继续从可见记录选取。刷新按钮补齐语义名称，加载／重试／加载更多固定在列表下方。
- 请求有明确生命周期，离开／刷新取消所属命令和后台解析；代次及项目身份阻止旧结果覆盖新状态。项目切换清除恢复分支的旧目标。
