# 0.4.41 差异分隔线与修改块标题

## 问题与实际原因

0.4.40中分隔线叠在LazyVStack整篇内容上。在根目录.diff-layout-qa的2,000行／100个修改块中：滚到约第1,000行，真实鼠标拖动392→322pt、方向键322→326pt均保留阅读位置；对该分隔线执行可访问性Decrement后却回到顶部。此前不能笼统称所有调整列宽都跳转。

## 调整

- 分隔线改为滚动视图可见区域的overlay，生命周期及尺寸跟随当前视口，保留原有拖动、双击、方向键和可访问性动作，不插入额外内容或缓存。
- 候选版同一仓库滚到中部，再执行可访问性Decrement，列宽302→278pt，仍显示第997至1021行，纵向值约0.502；不再定位到顶部。
- 双栏修改块标题将操作按钮放左列，范围说明放右列，两者受列宽约束，避免文本穿过分隔线；统一模式保留同一行布局，原动作与块索引不变。
