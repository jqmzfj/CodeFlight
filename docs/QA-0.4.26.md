# 0.4.26 命令面板键盘交互

## 修改与原因

0.4.25 实测命令面板输入“设置”后，回车没有执行，行尾回车图标与实际行为不符。本轮增加方向键选择、所选行状态、回车执行与自动滚动；禁用操作不参与键盘选择，搜索无匹配时回车无操作。

原生 NSTextField 的字段编辑器处理导航／执行／取消，普通编辑命令交回系统；输入法有组合文字时不拦截这些操作。面板关闭回调后才执行命令，避免设置、运行配置与打开项目面板重叠。执行前再次检查项目身份与能力，退出或切换项目后不执行旧请求。运行入口统一使用当前配置，缺少配置时打开配置窗口，不直接运行未保存草稿。
