# 0.4.20 工作树与子模块窗口

## 修改

- 原生工作树窗口最低680×400、子模块680×420，并提供统一的尺寸拖动手柄；继续保留可调左右分栏和可滚动表单。
- 移除两窗口失败诊断的8行截断，等宽可选择文本、轻量反馈背景，错误出现后自动滚到诊断开头；选择不同对象后回到内容顶部。
- 子模块列表在操作／刷新中禁用，选择绑定也检查busy／loading，避免操作中更换对象；表单在读取列表时禁用。添加状态切换后回到表单开头。
- 两窗口增加未保存标记。异步列表读取校验项目身份；移除选择变化回调中对失败信息的无条件清空，防止读取失败且自动选择变化时丢失错误。
