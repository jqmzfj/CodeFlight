# 0.4.28 主App文本预览诊断

## 范围

新增默认关闭的本地诊断。显式设置环境变量CODEFLIGHT_PREVIEW_TRACE为绝对.jsonl路径时，记录openFilePath处理入口到读取结果、后台准备结果、AppKit文本首次draw返回的分段时间，以及起始／绘制时RSS、进程生命周期峰值RSS。只记录文件basename，不记录源码或完整路径；后台串行写入，总文件上限1MiB。普通启动不创建诊断器或输出文件。

只覆盖切换到文本预览，不覆盖空／二进制／失败状态、同一文件重复点击、搜索／滚动、项目恢复，也不包含事件进入处理函数前的排队和WindowServer实际呈现。进程峰值包含启动及此前所有操作，不应误称单次打开峰值。新请求覆盖旧请求，切换项目／关闭预览／打开差异取消待测记录。
