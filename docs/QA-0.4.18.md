# 0.4.18 文件搜索导航与预览布局

## 修改

- 文件搜索新增上一处／下一处、回车、⌘G／⇧⌘G；保持搜索框焦点，原生选区与查找指示提示定位。首尾循环，Unicode偏移按UTF-16与TextKit保持一致。
- 匹配扫描在可取消后台任务执行，保存常数个匹配范围，不为每个结果构建索引数组。选择、查询或文档变化后过期结果不再改变选区；切换文件清理导航请求，路径保护防止跨文件回放。
- 滚动／缩放的bounds通知不再同步着色中间几何；在下一主线程周期合并，并在最终几何下着色。detach清空滚动视图引用，避免已移除视图的排队着色。
- 更新独立预览基准脚本的编译依赖，保留可运行的组件测量入口。
