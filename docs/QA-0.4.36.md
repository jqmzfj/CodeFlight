# 0.4.36 预览重复着色开销

## 实现

原生预览的bounds变化通知已做异步合并，但每次最终通知仍会移除当前视口全部临时颜色、ensureLayout、重新逐行分词与着色；滚动不足一行时也重复执行。

Coordinator仅保留最近一次视口身份：文档UUID、UTF-16范围、语言、查询、原生appearance名称、文本容器大小。全部一致时跳过重复排版／着色，但仍重绘行号栏以跟随小数滚动偏移。文档替换与detach清理身份；搜索、主题、容器尺寸及新行进入仍执行完整路径。不缓存额外文本／属性副本或历史视口，不预热全文件字形。

## 对照证据

直接优化编译生产源码的同一个组件探针，每种文件每方案3个新进程，原方案／优化方案交替运行，共24条；暖OS磁盘缓存。新增显式--scroll-bursts开关，在已排版中部视口做120次0–1.75pt往返，每次highlight与bitmap绘制均计时，不运行事件循环的自动通知。它衡量手工触发的重复工作，不是120Hz硬件滚动或输入到屏幕延迟。
