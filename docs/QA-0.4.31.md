# 0.4.31 多行代码词法上下文

原有预览仅对可见单行执行正则，滚入跨行注释／字符串中间会错误显示关键词和数字颜色；结束分隔符也可能被当作新字符串开始。

增加后台准备的不可变UTF-16字符串／注释区间，原生预览按可见行二分查询交集，只在其余区间处理关键词／数字。复用现有有界文件读取、行数和长行上限，新增区间成本计入24MiB／3项LRU。扫描定期检查任务取消；切换文档使用新索引，滚动不重扫前面的源码。独立性能探针也传递文件语言，避免漏测索引准备。

本轮涵盖C风格块注释、Swift／Rust等嵌套块注释、Python／Swift等三引号、Go原样字符串、JS／TS模板字符串、Swift井号原样分隔符与SQL双单引号转义。不是完整编译器语法解析；模板插值内部语义、PHP heredoc、YAML块字符串等仍有覆盖边界，长行／文件截断仍按预览上限提示。

## 组件性能范围

优化编译的现有生产组件探针传入真实文件扩展名，包含索引准备。独立新进程各3次，磁盘可能为暖缓存；不是主App处理入口到绘制、设备显示延迟或P95。原始15条记录存于preview-performance-0.4.31.json。

- 200行：准备中位8.34ms，安装并绘制33.35ms，结束时RSS66.30MiB。
- 1万行中英／emoji：准备144.10ms，首绘48.67ms，中部46.43ms，结束时RSS77.31MiB。
- 源12万行／展示10万行中英／emoji：准备1728.60ms，首绘110.41ms，中部497.08ms，末尾17.93ms；准备后RSS65.05MiB，结束时RSS212.42MiB。此处RSS是阶段值，不是峰值；十万行跨度首绘仍有约半秒延迟待优化。
- 三类样本缓存均复用ID，往返查询中位0.01／0.01／0.02ms；4MB单行按既有限制截断显示，2GB稀疏二进制保持非文本。
- 基准脚本生成的根目录随机夹具随脚本成功退出自动清理。本轮没有同时构建影响采样，不能与不同夹具的0.4.28实际主App样本直接作前后性能比较。
