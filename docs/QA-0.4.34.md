# 0.4.34 运行配置窗口布局与焦点

## 问题与实现

0.4.33最终App运行配置窗口实际观察：已有柔性frame但未接入resizableSheet，缺少其余管理窗口已有的原生缩放及键盘调整支持；标签与输入之间和字段之间使用相同15pt间距，表单偏松。新增／复制／导入后未主动聚焦名称；图标的AX名称退回系统“添加／移除／拷贝”。

- 接入既有resizableSheet，最低620×460pt，保留左右分隔线、命令和环境区域的独立高度调整，以及滚动表单和固定底部操作。
- 字段标签与内容间距6pt，字段组间14pt；自动运行说明和开关同组，减少无意义空隙。
- 新增／复制／导入后将焦点交给对应配置名称，普通列表切换不强制跳走。
- 文本编辑器、工作目录、目录选择、配置列表和图标提供直接的中英语义标签；错误可悬停读取完整内容。
- Windows版按用户要求暂不开发，README及质量范围已更新。
