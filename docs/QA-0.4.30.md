# 0.4.30 背景图失败与恢复

## 问题与修改

背景图不可读时旧实现静默变为空背景，选择仍是图片，用户不知道原因。启动时文件路径不存在还会直接丢掉图片选择，使恢复文件后也无法重试。

每窗口背景加载器增加idle／loading／ready／failed状态，与设置页共享该对象。加载时展示进度，失败显示可换行说明，并提供重试／使用纯色及原有更换图片入口，不新增弹窗。保留失效路径的图片偏好，让重启后仍可看到错误并恢复。切换任务取消旧解码，按请求身份拒绝过期结果；解码期间保留原位图，取消替换恢复稳定状态，切回纯色清空待加载结果。后台下采样最长2560像素的上限保留。
